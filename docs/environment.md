# Môi trường build

Điền từ máy hoặc môi trường đã clean build thành công.

| Thuộc tính | Giá trị hiện tại |
|---|---|
| Linux distribution và version | Chưa thu |
| WSL version hoặc native Linux | Chưa thu |
| Host architecture | Chưa thu |
| Danh sách package và version | Chưa thu |
| Toolchain cho từng component và ABI | Chưa thu |
| URL và SHA-256 toolchain | Chưa thu |
| Python/Make/CMake/Ninja/DTC theo thực tế | Chưa thu |
| Quartus/SoC EDS nếu cần cho baseline | Chưa thu |
| Nhu cầu RAM/disk đã đo | Chưa thu |
| Container image digest nếu sử dụng | Chưa thu |

Không tự chọn version mới nhất khi viết lại tài liệu. Nếu dùng container, vẫn cần giữ các công cụ ngoài container và bước flash/serial của host trong hướng dẫn.

Đường dẫn /home/manhlinh/secure_imgproc là vị trí lịch sử trên máy tác giả. Script trong repo phải chạy được dưới một thư mục clone khác.
