# ISSUE ID và triệu chứng

## Trạng thái
OPEN / INVESTIGATING / WORKAROUND / FIXED.

## Phiên bản bị ảnh hưởng
Project commit, component commit, patch/config hash, run_id, build_id, board và toolchain.

## Cách tái hiện
Prerequisite, môi trường chạy, lệnh nguyên văn, kết quả mong đợi và kết quả thực tế.

## Bằng chứng
Log đầy đủ, đoạn trích liên quan, địa chỉ fault, ELF/map tương ứng và liên kết evidence.

## Phân tích
Tách rõ dữ kiện quan sát, giả thuyết và nguyên nhân đã xác nhận.

## Các lần thử
Mỗi attempt: thay đổi duy nhất hoặc diff cụ thể, artifact hash, lệnh test và kết quả.

## Cách sửa
Commit/patch, lý do sửa và phạm vi ảnh hưởng. Để “chưa có” nếu chưa xác nhận.

## Xác minh
Clean build, case lỗi cũ, regression cần thiết, log/exit code và known limitations.

## Liên kết
Daily, issue/PR, baseline bị ảnh hưởng và release chứa fix.
