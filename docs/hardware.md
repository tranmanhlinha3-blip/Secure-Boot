# Phần cứng và kết nối

Board quan sát trong log: Terasic DE10-Nano, Cyclone V SoC. Hoàn thiện bảng dưới bằng ảnh hoặc thông số của setup đã chạy.

| Mục | Cần ghi |
|---|---|
| Board | Revision, nhận dạng SoC và board_id của phiên test |
| Boot source | Switch/jumper và cách kiểm tra |
| UART | Cổng/pin, adapter và mức điện áp theo hướng dẫn board |
| Terminal | Baud, data/parity/stop, flow control đã dùng |
| SD | Dung lượng tối thiểu theo image, layout, cách nhận diện trên host |
| Power | Nguồn và trình tự bật/tắt, cold boot hay warm reset |
| FPGA | RBF/project tương ứng nếu scope có FPGA programming |
| Ngoại vi | Camera hoặc thiết bị khác chỉ khi phép thử cần |

Các giá trị chưa thu không được suy ra từ một spec minh họa. Đính kèm nguồn hướng dẫn phần cứng chính thức theo board revision khi hoàn thiện.
